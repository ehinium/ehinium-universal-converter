# Ehinium Universal Converter

Open-source browser extension for automatic currency and unit conversion across websites.

## Features (Free)

* Automatic fiat currency conversion
* Hover conversion
* Unit conversion
* Website whitelist
* Website blacklist
* Fast local caching
* Beautiful and simple UI

## Planned Premium Features

* Cryptocurrency conversion
* Gold and precious metals
* Custom exchange rates
* Fee percentages
* Multiple profiles
* Cloud sync

## Exchange Rate Providers

Primary:

* Frankfurter API

Fallback:

* Fawaz Ahmed Currency API

## Tech Stack

* React
* TypeScript
* Vite
* Browser Extension APIs
