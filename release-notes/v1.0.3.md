EUC 1.0.3 fixes conversions on shops built with web components and on pages that hid badges after scrolling.

- **Prices inside web components convert.** Shops such as Pull&Bear and Stradivarius draw each price inside its own component, where EUC could not see it. Both the sale price and the crossed-out price now convert.
- **Badges stay visible when you scroll.** On sites such as Adidas, every conversion below the first screen stayed hidden. They now appear as soon as the price scrolls into view.
