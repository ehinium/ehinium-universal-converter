EUC 1.0.1 brings back Iranian rial and toman (IRT) conversions.

- **IRT rates load again.** The address EUC used for Iranian market rates stopped working, so IRT conversions showed no rate. EUC now fetches those rates from its own API at `api.euc.tools`, and the extension's host permission changes from the old address to this one.

Nothing else changes from 1.0.0.
