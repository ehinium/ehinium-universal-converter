# Release Process

1. Run `npm install`.
2. Run `npm run check`.
3. Run `npm run build:release`.
4. Run `npm run package:release`.
5. Load unpacked `dist` in Chrome for final QA.
6. Test using `docs/release-regression-checklist.md`.
7. Upload `release/ehinium-universal-converter-0.1.0.zip` to the Chrome Web Store.
